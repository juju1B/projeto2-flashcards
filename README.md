# projeto2-flashcard
#Flashcards de Óptica na Robótica

Um sistema interativo e simples de cartões de estudo (flashcards) focado em conceitos de óptica física e geométrica aplicados ao desenvolvimento de robôs, sensores e visão computacional.

## Como Rodar o Projeto

1. Certifique-se de salvar os arquivos `index.html`, `style.css` e `script.js` na **mesma pasta**.
2. No VS Code, clique com o botão direito sobre o arquivo `index.html` e escolha **Open with Live Server** (requer a extensão Live Server instalada).
3. Caso não possua a extensão, basta dar um duplo clique no arquivo `index.html` diretamente pelo gerenciador de arquivos do seu sistema operacional.

## Tecnologias Utilizadas
- HTML5 (Estrutura semântica)
- CSS3 (Estilização responsiva e efeitos de rotação 3D)
- JavaScript Vanilla (Manipulação de dados e estados do DOM)
